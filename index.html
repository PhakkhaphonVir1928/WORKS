☁️

การนำเว็บลง Git & วิธีบันทึกข้อมูลที่อัปเดต

เลือกวิธีบันทึกข้อมูลให้เหมาะกับการใช้งานบน GitHub Pages / GitLab

💡 เวลาเอาเว็บ Static ขึ้น Git จะบันทึกข้อมูลที่อัปเดตยังไง? ปกติหน้าเว็บแบบ HTML ล้วนบน Git (เช่น GitHub Pages) จะบันทึกข้อมูลที่เพิ่มใหม่ไว้ใน LocalStorage ของเบราว์เซอร์เครื่องนั้นๆ ทันที แต่ถ้าต้องการให้คนอื่นในทีมเห็นข้อมูลชุดเดียวกันบน Git คุณสามารถกดปุ่มด้านล่างเพื่อดาวน์โหลดไฟล์ไป Commit ขึ้น Git ได้เลย:
📦 วิธีที่ A: ดาวน์โหลด index.html (ฝังข้อมูลล่าสุด)

ระบบจะสร้างไฟล์ index.html (เฉพาะดีไซน์แบบที่ 1) ที่มีข้อมูลทุกหมวด (RSM / MI / AMS / C&E) ที่คุณอัปเดตล่าสุดฝังอยู่ในไฟล์เดียว นำไปวางทับในโฟลเดอร์ Git แล้ว Push ขึ้นได้เลย

💾 วิธีที่ B: แยกไฟล์ข้อมูล data.json

ดาวน์โหลดเฉพาะข้อมูลเป็นไฟล์ data.json ไปวางคู่กับ index.html ใน Git Repo หรือกด Import ไฟล์ JSON จากเครื่องอื่นเข้ามา

⚡ บันทึกข้อมูลขึ้น GitHub โดยตรงจากหน้าเว็บ (ไม่ต้องใช้คำสั่ง Git) หากคุณโฮสต์เว็บไว้บน GitHub Pages คุณสามารถใส่ GitHub Personal Access Token (PAT) เพื่อให้ปุ่มบันทึกบนหน้าเว็บส่งข้อมูลไป Commit ทับไฟล์ data.json บน GitHub Repository ได้ทันที

ขั้นตอนการนำไฟล์ขึ้น GitHub และเปิดใช้งานหน้าเว็บผ่าน GitHub Pages:

1. เอาไฟล์ขึ้น Git Repository ครั้งแรก 
git init
git add index.html data.json
git commit -m "Initial commit: Knowledge & Query Base (RSM, MI, AMS, C&E)"
git branch -M main
git remote add origin https://github.com/ชื่อผู้ใช้/ชื่อ-repo.git
git push -u origin main
2. เวลาเพิ่ม/แก้ไขข้อมูลแล้วต้องการอัปเดตขึ้น Git 
# หลังกดปุ่ม Export data.json หรือ ดาวน์โหลด index.html มาวางทับในโฟลเดอร์โปรเจกต์
git add index.html data.json
git commit -m "Update knowledge base entries"
git push
